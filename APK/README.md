# APK 下载

本项目的 APK **不放在这个文件夹里**，统一走 GitHub **Releases** 发布：

👉 **[点这里打开 Releases 页面](../../releases)**

每个版本对应一个 Release，附件里就是打包并签名好的 APK。

这样做的好处：

- 附件**不计入仓库体积**，换版本不会把仓库越滚越大
- 每个版本有独立下载页，直链可以直接分享：
  `https://github.com/<你的用户名>/MyMediaApp/releases/download/<tag>/<APK 文件名>.apk`
- 历史版本随时可回溯，不用翻 Git 提交记录
